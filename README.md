# 🎯 LAKSHYA — Turn Study Into a Quest

A gamified study platform that turns daily study tasks into XP-earning quests, with streaks, achievements, AI assistance, and email verification.

## ✨ Features

- 🔐 Secure authentication with hashed passwords
- 📧 Email OTP verification on registration
- 🎯 Daily quests with XP rewards (30 / 50 / 100 / 150)
- 🔥 Study streak tracking
- 🏆 12 achievements with unlock tracking
- 📈 Level progression with titles (Novice → Learner → Scholar → Expert → Master → Legend)
- 🌅 Automatic daily task reset at midnight
- 🤖 AI study assistant powered by Google Gemini
- 💬 Persistent chat history (saved per user)
- 🎤 Voice input and text-to-speech
- 📱 Fully responsive design

## 🧱 Tech Stack

- **Backend:** Flask, Flask-SQLAlchemy, SQLite
- **Frontend:** Jinja2, vanilla JavaScript, custom CSS
- **AI:** Google Gemini API
- **Email:** Gmail SMTP with App Password
